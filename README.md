# Royal Solar Arena

Battle royale spaziale per mobile (landscape), file unico `index.html`. Versione **1.00**.

- 10 piloti, zona che si restringe verso il Sole, brillamenti, sciami di asteroidi, power-up
- 3 telai sbloccabili col livello, 3 difficoltà, pausa, tutorial al primo avvio
- Installabile (PWA) e offline: apri via HTTPS e "Aggiungi a Home"; schermo sempre acceso, schermo intero, vibrazione
- IA opzionale locale (Qwen2.5 1.5B) per nemici adattivi
