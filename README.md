# Royal Solar Arena

Battle royale spaziale per mobile (landscape), file unico `index.html`. Versione **1.10**.

- Grafica pixel art: palette master da 91 colori con dithering ordinato, pianeti a rampe di materiale, stelle a sprite, Sole con corona e protuberanze, nave e effetti ridisegnati, UI e titoli con font bitmap
- 10 piloti, zona che si restringe verso il Sole, brillamenti, sciami di asteroidi, power-up
- 3 telai sbloccabili col livello, 3 difficoltà, pausa, tutorial al primo avvio
- Bot con IA scriptata (mira predittiva, schivata, esplorazione): nessun download, tutto offline
- Installabile (PWA) e offline: apri via HTTPS e "Aggiungi a Home"; schermo sempre acceso, schermo intero, vibrazione
